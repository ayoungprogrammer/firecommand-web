Fire Command

Tactical Firefighting Real-Time Strategy

Controls

  • Left Click Select / Place
  • Right Click Move / Cancel
  • Drag Box select
  • WASD Pan camera
  • Scroll Zoom
  • ESC Pause

Units

  • Firefighters - Infantry, unlimited water
  • Fire Trucks - Fast, water tanks
  • Helicopters - Aerial water drops

Actions

  • Smokejumper - Deploy firefighter
  • Phos-Chek - Fire retardant line
  • Satellite - Reveal 25x25 area

Objectives

  • Extinguish all fires
  • Protect structures
  • Watch the wind!
  • Use smoke as intel

Fire Command - Built with Godot 4.5
